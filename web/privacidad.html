Cómo funciona esta web

Los campos de consulta preparan un texto dentro de tu navegador. No se envían a un servidor de Aireal ni se guardan en una base de datos de esta web. Al elegir «Abrir mi correo», el navegador entrega el borrador a tu aplicación de email. Tú decides si lo envías. Copiar y descargar son acciones locales. El navegador puede ofrecer su propia función de autocompletado.

Consultas que envías por correo

Si envías el email, se recibirán los datos incluidos, como nombre, dirección de correo, negocio y contenido de la consulta. Se utilizarán para atender tu solicitud y preparar, en su caso, una propuesta. La base prevista para una consulta sobre contratación es la aplicación de medidas precontractuales solicitadas por ti. No se te suscribe a publicidad por preparar o enviar una consulta.
